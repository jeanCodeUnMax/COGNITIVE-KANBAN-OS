# PRD — Cognitive Kanban OS

## Problème
Les créateurs techniques peuvent formuler une vision riche mais se retrouvent bloqués entre cette vision et la première action : surcharge, découpage incertain, multiplication des idées, dépendance à un assistant coûteux et perte du fil après interruption.

## Proposition de valeur
Transformer une intention en un flux vivant : **capturer → clarifier → architecturer → découper → exécuter → vérifier → apprendre**.

## Persona initial
Créateur solo ou petite équipe, riche en idées, compétences techniques intermédiaires, plusieurs projets concurrents, budget IA limité, besoin d’un système qui réduit la charge décisionnelle.

## V1
- capturer un objectif et ses contraintes ;
- générer un workspace et un backlog initial ;
- imposer une limite d’un item en cours ;
- proposer la prochaine action ;
- découper une carte ;
- déplacer les cartes et produire une vue Markdown ;
- intégrer des skills Claude Code réutilisables ;
- fournir des tests automatiques.

## Hors périmètre V1
Interface graphique, agents parallèles permanents, facturation SaaS, synchronisation cloud, sélection automatique multi-fournisseurs, autonomie destructive, marketplace de skills.

## Indicateurs
- temps entre idée et première carte prête ;
- pourcentage de cartes terminées sans redécoupage ;
- nombre moyen de cartes en cours ;
- coût tokens par carte terminée ;
- taux de critères d’acceptation validés.
