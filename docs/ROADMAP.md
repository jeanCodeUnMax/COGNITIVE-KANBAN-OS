# Roadmap

## Phase 1 — Outil personnel fiable
CLI locale, Kanban vivant, skills, une seule action à la fois, preuves de fin.

## Phase 2 — Assistant architecte
Connexion Ollama/Claude/OpenAI, génération de PRD et backlog, coût routé selon complexité.

## Phase 3 — Boucle d’exécution
Exécution contrôlée, tests, correction limitée, journal, arrêt sur budget ou incertitude.

## Phase 4 — Produit
Interface cockpit, modèles de projets, comptes, export GitHub, métriques de progression.

## Phase 5 — Offre commerciale
Starter gratuit, version Pro locale, packs de skills métiers, accompagnement et marketplace.
